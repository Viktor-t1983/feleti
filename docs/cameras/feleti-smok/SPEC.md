- Бюджетная комплектация, упрощённый контроллер.
- Mini-Hot (горячее) и Mini-Cold (холодное + охлаждение) для крафта.

## 3. Контроллер

### 3.1. Kinco HMI/PLC

**Выбор серии (обоснование):**
- **HMI:** MT 4514 (10.1", 1024×600, резистивный сенсор, Ethernet, 2×RS-485, USB-host) — стандарт для среднеразмерных промышленных панелей.
- **PLC:** K7 (модульный, до 32 I/O, Ethernet, Modbus TCP/RTU, ПИД-регулятор) — надёжный, документированный, сервисная поддержка в РФ через дистрибьюторов.

**Модули I/O (предварительно):**
- 1× CPU (K720) с Ethernet
- 2× DI 16 (32 дискретных входа: концевики, датчики, кнопки)
- 2× DO 16 (32 релейных выхода: ТЭН, вентилятор, дымоген., заслонки, замок)
- 2× AI 8 (16 аналоговых входов: Pt100×4, влажность, дым, ΔP, ток, напряжение)
- 1× AO 4 (4 аналоговых выхода: VFD вентилятора, мощность дымогенератора, эл.поле, заслонка)

**HMI-программа (Kinco DTools):**
- Экран 1: Состояние камеры (T_chamber, T_product, влажность, дым, текущая фаза).
- Экран 2: Программа (список фаз, t/time, прогресс-бар).
- Экран 3: Ручной режим (ручное управление ТЭН/вентилятор/дым для отладки).
- Экран 4: Аварии (журнал ошибок, квитирование).
- Экран 5: Настройки (IP, Modbus, сервис).

**Fallback:** при потере связи с верхним уровнем (FELETI-SMOK backend) Kinco продолжает выполнять загруженную программу автономно.

### 3.2. Свой модуль расширения

**Hardware-платформа:** **Raspberry Pi CM4** (Compute Module 4) — компактный, индустриальный (-40..+85°C), есть в наличии у поставщиков, Linux, Python.
- 4×USB, 2×Ethernet, GPIO, eMMC 16–32 ГБ, WiFi/BT (опц.).
- Питание 5В/3А, 12–24В через DC-DC.
- Корпус: DIN-рейка или встроен в щит камеры.

**Альтернатива (бюджетная):** **ESP32-S3** + **RS-485** (Modbus RTU slave) — если нужно сильно удешевить. Ограничение: нет Linux, прошивка на C/MicroPython.

**ПО модуля расширения:**
- **OS:** Raspberry Pi OS Lite (64-bit).
- **Runtime:** Python 3.11 + FastAPI (для локального REST API, опц.) или просто pymodbus server.
- **Modbus TCP server:** порт 503 (slave), регистры доп. датчиков.
- **MQTT клиент:** публикация телеметрии в облако (опц.).
- **Edge-cache:** SQLite с рецептами (синхронизация с backend).
- **TFLite runtime (опц.):** для локального anomaly detection.

**Зачем нужен свой модуль:**
1. **Электростатика** — высоковольтный блок (10–30 кВ), требует отдельной безопасной развязки от Kinco.
2. **Доп. датчики** — термокарта (multi-Pt100), ΔP, газоанализатор, pH — нужны быстрые опросы, Kinco AI может не хватить.
3. **Edge-AI** — локальный ML-инференс (аномалии, авто-коррекция программы) — не нагружает Kinco.
4. **MQTT-мост** — Kinco Modbus TCP не умеет MQTT, нужен посредник.
5. **OTA-обновления** — свой модуль обновляется из облака, Kinco остаётся стабильным.
6. **IP-защита** — наша разработка, не зависим от Kinco-прошивки.

## 4. Дымогенератор (собственный)

### 4.1. Конструкция
```
┌────────────────────────────────────────────────┐
│  1. Бункер щепы (5–10 кг)                       │
│     └─ шнековая автоподача (VFD)                │
│  2. Зона пиролиза (электронагрев, 400–600°C)   │
│     └─ контроль t (термопара)                   │
│  3. Зона дымообразования                        │
│     └─ смешивание с воздухом (вентилятор)       │
│  4. Камера сгорания                             │
│     └─ отстойник золы (авто-выгрузка)           │
│  5. Выход дыма → коллектор → камера             │
│                                                │
│  6. ФРИКЦИОННЫЙ ГЕНЕРАТОР (опц./основной)        │
│     └─ диск (нержавейка, ⌀ 300 мм)             │
│     └─ прижимная планка (дерево/вставка)        │
│     └─ мотор-редуктор (1.5 кВт, 300 об/мин)    │
│                                                │
│  7. АТОМАЙЗЕР (для электростатики)               │
│     └─ ёмкость для жидкого дыма (1–2 л)         │
│     └─ пневматический распылитель (2–4 бар)     │
│     └─ производительность 50–200 мл/мин         │
└────────────────────────────────────────────────┘
```

### 4.2. Режимы работы
| Режим | Дым | Т дыма | Применение |
|---|---|---|---|
| **Щепа (классика)** | Пиролизный, плотный | 200–400°C | Горячее копчение, длительное |
| **Фрикционный** | Мелкодисперсный, «лёгкий» | 80–150°C | Электростатика, быстрое копчение |
| **Атомайзер** | Жидкий дым, аэрозоль | Комнатная | Электростатика с жидким дымом |
| **Комбо** | Щепа + атомайзер | 150–250°C | Профессиональное |

### 4.3. Управление
- **Modbus-регистры:** расход щепы (г/мин), t зоны пиролиза, t дыма, мощность фрикционного, расход атомайзера (мл/мин).
- **Датчики:** t зоны пиролиза (термопара), t дыма (Pt100), датчик уровня щепы (опт./вес), датчик расхода воздуха.

## 5. Электростатика (опция — апгрейд-модуль)

### 5.1. Параметры
- **Напряжение:** 10–30 кВ (плавная регулировка).
- **Ток:** 2–50 мкА (токоограничение для безопасности).
- **Полярность:** отрицательная (стандарт для копчения).
- **Электроды:** сетка/пластина из нержавейки AISI 304, ⌀ 2–4 мм, шаг 30–50 мм.
- **Расстояние до продукта:** 100–300 мм.
- **Зона:** по всей высоте камеры.

### 5.2. Безопасность
- Блокировка двери (не подавать HV при открытой двери).
- Токоограничение (защита от КЗ).
- Заземление корпуса.
- Изоляция HV-ввода.
- Индикатор «HV ON» на HMI.
- Аварийное отключение.
- **Требования:** соответствие ТР ТС 004/2011 (низковольтное), ТР ТС 020/2011 (ЭМС).

### 5.3. Управление
- **Modbus-регистры:** set_voltage (0–300 = 0–30 кВ), actual_voltage, actual_current, enable (bool).
- **Профиль копчения:** напряжение нарастает в первые 5 мин, стабильное 15–25 кВ, спад в последние 5 мин.
- **Совместимость:** только с фрикционным или атомайзером (классический щепа даёт крупные частицы, малоэффективно).

## 11. Типовые программы копчения (референсные, для FELETI-SMOK Profi)

### 11.1. Горячее копчение (H-линейка)

**Скумбрия г/к, 80 кг:**
1. Подсушка: 30 мин, +30°C, влажность 30%, без дыма.
2. Копчение: 60 мин, +80°C, влажность 50%, дым средний (ольха).
3. Готовка: 30 мин, +90°C, влажность 70%, без дыма, до T_product +78°C.
4. Охлаждение: 20 мин, +20°C.
**Итого:** ~140 мин.

**Курица целиком г/к, 50 кг:**
1. Подсушка: 20 мин, +40°C, влажность 30%, без дыма.
2. Копчение: 180 мин, +75°C, влажность 50%, дым средний (ольха/яблоня).
3. Готовка: до T_product +74°C.
4. Охлаждение: 30 мин, +20°C.
**Итого:** ~4–5 ч.

### 11.2. Электростатическое копчение (H-линейка, опция ELE)

**Скумбрия электро, 80 кг:**
1. Подсушка: 20 мин, +25°C, влажность 40%, без дыма.
2. Электро-фаза: 90 мин, +40°C, дым лёгкий (фрикционный), **20 кВ, 25 мкА**.
3. Стабилизация: 30 мин, +50°C, без дыма и электро.
4. Охлаждение: 20 мин, +20°C.
**Итого:** ~160 мин (в 2–3 раза быстрее классики).

### 11.3. Холодное копчение (C-линейка, Profi Cold)

**Сёмга х/к, 80 кг:**
1. Предварительное охлаждение: 60 мин, +4°C (выход на рабочую t).
2. Подсушка: 90 мин, +18°C, влажность 60%, без дыма.
3. Копчение холодное: 12–18 ч, +20±2°C, влажность 55–65%, дым лёгкий (ольха, тонкая щепа).
4. Подвяливание: 2 ч, +18°C, без дыма.
5. Охлаждение до +4°C: 60 мин (предпродажная подготовка).
**Итого:** 16–24 ч.

**Скумбрия х/к, 80 кг:**
1. Предварительное охлаждение: 30 мин, +4°C.
2. Подсушка: 60 мин, +18°C, влажность 60%.
3. Копчение холодное: 12–16 ч, +20°C, влажность 60%, дым лёгкий (ольха).
4. Охлаждение: 30 мин, +4°C.
**Итого:** 14–18 ч.

**Сыр «Российский» х/к, 50 кг:**
1. Охлаждение сыра до +8°C (предварительно, до загрузки).
2. Подсушка: 30 мин, +18°C, влажность 55%.
3. Копчение: 2–4 ч, +18°C, влажность 60%, дым очень лёгкий (ольха или ольха+яблоня).
4. Охлаждение: 30 мин, +8°C.
**Итого:** 3–5 ч.

**Сало х/к, 50 кг:**
1. Предварительное охлаждение: 60 мин, +4°C.
2. Подсушка: 120 мин, +18°C, влажность 55%.
3. Копчение: 8–12 ч, +20°C, дым лёгкий (ольха, можно +чеснок в фарш).
4. Охлаждение: 60 мин, +4°C.
**Итого:** 12–16 ч.

### 11.4. Полугорячее копчение (H-линейка, расширенный режим)

**Сельдь п/к, 50 кг:**
1. Подсушка: 20 мин, +30°C, влажность 30%.
2. Копчение: 60 мин, +50°C, влажность 50%, дым средний.
3. Подвяливание: 30 мин, +40°C, без дыма.
4. Охлаждение: 20 мин, +15°C.
**Итого:** ~130 мин.

### 11.5. Охлаждение (только C и U, как отдельный режим)

**Охлаждение партии после г/к (предпродажная подготовка):**
- 60–120 мин, +4°C, влажность 85–90%.
- Цель: быстро охладить продукт до безопасной температуры хранения.
- Соответствует СанПиН 2.3/2.4.3590-20.

**Хранение готовой продукции (в камере, не более 12 ч):**
- +2…+4°C, влажность 78–82%.
- Дверь закрыта, вентилятор на минимум.

### 11.6. Заморозка (опция, не в базе C-линейки, но в U)

**Шоковая заморозка рыбы:**
- -18°C, влажность любая, 4–6 ч до -18°C в центре.
- Для длительного хранения полуфабриката перед копчением.
- Опция: добавить в `C-Ultra` версию (Profi C с расширенным диапазоном до -25°C).
