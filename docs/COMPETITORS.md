## 2. Детальный профиль ключевых конкурентов

### 2.1. Ижица (главный конкурент)

**Продуктовые линейки:**
- **Horeca** (20–100 кг): Varmen Mini, Varmen-1, Varmen-2, UTR.30, UTR.50, UTR.100, Z115-25, Z115-50.
- **Profi** (100–250 кг): Varmen-3, UTR.150, UTR.250, DL400, DL450.
- **Industrial** (250+ кг): DL800, DL1200, UTR.500, конвейерные.

**Ключевые технологии:**
- **Электростатическое копчение** 10–30 кВ, ток 2–50 мкА — осаждение дыма на продукт в электрическом поле.
- **Атомайзер Varmen Atomic** — мелкодисперсный дым с высокой проникающей способностью.
- **Фрикционный дымогенератор** Ф10/F15 — трение дерева о диск (без пиролизного дыма).
- **Щеповой дымогенератор** DL400/DL450 — классический пиролиз щепы ольхи/бука/дуба.
- **Программируемые фазы** — 8–16 шагов с автопереходом по температуре продукта/времени.
- **Автоматическая мойка CIP** (в Industrial-линейке).

**Софт (слабое место):**
- Закрытая утилита под Windows, **нет mobile**, **нет web**.
- Рецепты хранятся локально на ПК, нет синхронизации.
- Нет версионирования, нет workflow, нет базы знаний.
- Нет удалённого мониторинга (только RS-485/Modbus на месте).
- **Цена софта/лицензии** — отдельная доплата.

**Цены (ориентир 2024):**
- Varmen Mini (20 кг) — от 350k ₽
- Varmen-1 (50 кг) — от 580k ₽
- Varmen-2 (100 кг) — от 950k ₽
- UTR.250 (250 кг) — от 1.8M ₽
- DL800 (промышленная) — от 3.5M ₽

**Слабые стороны (наши возможности):**
- Закрытый протокол → FELETI-SMOK **открытый Modbus TCP** + облако.
- ПК-софт → FELETI-SMOK **PWA** (desktop+mobile из коробки).
- Нет версионирования рецептов → FELETI-SMOK **draft→pending→approved→archived**.
- Нет базы знаний → FELETI-SMOK **встроенный Copilot** с RAG.
- Цена +10–15% на top-end → FELETI-SMOK **на 10–15% дешевле**.

---

### 2.2. Mauting (Чехия)

**Сильные стороны:**
- Очень надёжные туннели 1–6 вагонеток, 2–8 в двухрядных.
- Промышленная автоматика Siemens.
- Многолетняя репутация в Европе.

**Слабые стороны:**
- Закрытая SCADA, нет mobile.
- Цена высокая, в РФ — сложно с сервисом и запчастями.
- Нет cloud-телеметрии.

**Сравнение:** Mauting — премиум для крупных заводов; FELETI-SMOK — выигрываем в **цене/сервисе/софте** для среднего сегмента.

---

### 2.3. Fessmann (Германия)

**Сильные стороны:**
- **FES.APP** — мобильное приложение для iOS/Android (редкость в отрасли).
- **FOOD.CON 2** — современный контроллер.
- Серия **Turbomat** — запатентованная схема (вентилятор + нагреватель + продукт).
- **ECO.LiNE** — энергоэффективная линейка.
- **RZ 325** — собственный дымогенератор.
- **CIP-мойка** интегрирована.

**Слабые стороны:**
- Цена в 2–3 раза выше Ижицы.
- FES.APP — mobile-only, нет полноценного web-дашборда.
- Нет версионирования рецептов в облаке.
- Нет RAG-ассистента.

**Сравнение:** Fessmann — премиум с лучшим mobile UX. FELETI-SMOK берёт **открытостью (Modbus TCP), ценой, встроенной базой знаний и Copilot**.

---

### 2.4. Kerres (Германия)

**Сильные стороны:**
- **Jet Smoke** — струйная подача дыма (быстрое копчение).
- **Hybrid Airflow** — комбинация принудительной и естественной конвекции.
- Модульная конструкция из нержавейки.
- Climate control высокой точности.
- Интегрированные системы мойки.

**Слабые стороны:**
- Сложный OPC UA, нужны специалисты для интеграции.
- Цена высокая.
- Софт в основном на HMI панели оператора.

**Сравнение:** Kerres — нишевые технологии для премиум-сегмента. FELETI-SMOK берёт **простотой интеграции (Modbus TCP)** и **облачной аналитикой**.

---

### 2.5. AGROS (Словения)

**Сильные стороны:**
- Хорошее соотношение цена/качество для среднего бизнеса.
- Универсальные камеры с базовой автоматикой.

**Слабые стороны:**
- Софт устаревший, Windows-only.
- Нет mobile, нет cloud.
- Слабая локализация для РФ.

**Сравнение:** прямой конкурент FELETI-SMOK в среднем сегменте. Выигрываем за счёт **PWA, cloud, AI**.

## 5. Стратегия выхода на рынок

### 5.1. Целевые сегменты
1. **Малый/средний крафт** (пекарни, крафтовые колбасные, фермерские рыбы) — Horeca Mini/Horeca.
2. **Региональные мясопереработчики** — Horeca/Profi.
3. **Сети общепита** (централизованное производство) — Profi/Industrial.
4. **Крупные мясокомбинаты** — Industrial (в долгосрочной перспективе).

### 5.2. Каналы продаж
- Прямые продажи (B2B).
- Дилерская сеть в РФ/СНГ.
- Маркетплейсы оборудования (Авито, Пульс цен).
- Выставки (ПродЭкспо, WorldFood, Seafood Expo).

### 5.3. Ключевые УТП в маркетинге
1. **«Открытая камера»** — Modbus TCP, можно интегрировать со своим софтом.
2. **«Всё в телефоне»** — PWA, можно управлять с любого устройства, оффлайн.
3. **«Рецепты не теряются»** — иммутабельная история, workflow-апрув, версионирование.
4. **«ИИ-копилот»** — встроенный ассистент с базой знаний по копчению.
5. **«Голосовое управление»** — hands-free в цеху (Whisper + intent).
6. **«Дешевле Ижицы на 10–15%»** — при сопоставимом качестве.
7. **«Бесплатная база знаний»** — 30+ рецептов, ГОСТы, troubleshooting.
