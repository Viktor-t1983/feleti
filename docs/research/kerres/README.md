## 4. Особенности Kerres
- Немецкое качество, 60+ лет.
- Jet Smoke — струйная подача дыма, быстрое копчение.
- Hybrid Airflow — комбинация принудительной и естественной конвекции (равномерность).
- Модульная конструкция — гибкость под заказчика.
- Цены: 80 000 €+.

## 5. Что взять для FELETI-SMOK
1. **Jet Smoke** — добавить в свой дымогенератор опцию струйной подачи.
2. **Hybrid Airflow** — режим работы вентилятора (принудительный + естественный) — реализовать.
3. **Модульная конструкция** — проектировать Profi H/C/U как модули (тепло, холод, дым, электро).
