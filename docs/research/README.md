# Research — общий план парсинга конкурентов и базы знаний

> **Цель:** собрать максимум информации о коптильном оборудовании, технологиях и рецептах для наполнения базы знаний FELETI-SMOK и каталога камер/рецептов.
> **Главный конкурент — Ижица** (максимальный фокус), затем Mauting/Fessmann/Kerres/AGROS, остальные — по остаточному принципу.
> **Источники:** сайты, каталоги (PDF), YouTube, Telegram, дилеры в РФ/СНГ.

## 3. Источники данных (детально)

### 3.1. Сайт Ижица (ijiza.ru)
**Что парсить:**
- Главная, каталог продукции.
- Каждая модель (Varmen Mini, Varmen-1, Varmen-2, UTR.30–500, DL400–1200, Z115, Ф10/Ф15).
- Контроллер Varmen-1 (если есть документация).
- Рецепты (если есть раздел).
- Дилеры (контакты, регионы).
- Цены (если публикуются; иначе — диапазоны с пометкой «по запросу»).

**Скрипты:** `backend/app/services/web_parser.py`.

**Ограничения:**
- Не ломать robots.txt.
- User-Agent хорошего бота.
- Rate-limit: не чаще 1 запроса в 2 сек.
- Кэшировать HTML, не парсить повторно.

### 3.2. PDF-каталоги Ижица
**Что парсить:**
- Каталог продукции (2023/2024).
- Технические паспорта на модели.
- Инструкции по эксплуатации.
- Прайс (если публикуется).
- Схемы подключения.

**Скрипты:** `backend/app/services/pdf_parser.py` (pdfplumber + PyMuPDF).

### 3.3. Telegram-каналы

| Канал | Фокус | Статус |
|---|---|---|
| `@ijiza_chat` | Обсуждение камер Ижица, опыт операторов | 🚫 нужен API + вступление |
| `@smoking_tourney` | Технологии, новинки, соревнования | 🚫 |
| `@gurukopcheniya` | Домашнее и крафтовое копчение, рецепты | 🚫 |
| `@pro_kopcheno` | Профессиональное копчение, обучение | 🚫 |
| `@gradus_haus` | Домашнее копчение, рецепты | 🚫 |

**Что извлекать:**
- Рецепты (в т.ч. с фото и параметрами).
- Программы копчения (T_chamber, T_product, время, щепа).
- Проблемы и решения.
- Отзывы на оборудование.
- Сравнения с другими камерами.
- Контакты технологов (с разрешения).

**Скрипты:** `backend/app/services/telegram_parser.py` (Telethon).

**Юридические ограничения:**
- Только публичные каналы.
- Не перепубликовывать посты.
- Использовать как reference для своих рецептов.
- Указывать источник.

### 3.4. YouTube-каналы и обзоры

**Что парсить:**
- Обзоры конкретных моделей: «Ижица Z115A обзор», «KERRES системы», «Klima 107».
- Сравнительные тесты: «Ижица vs Mauting».
- Технологические видео: «электростатическое копчение», «холодное копчение сёмги».
- Мастер-классы от шефов.

**Скрипты:** `backend/app/services/youtube_parser.py` (yt-dlp + Whisper).

**Что извлекать:**
- Транскрипция (рус/eng).
- Тайм-коды ключевых моментов.
- Параметры программ.
- Ошибки, проблемы.
- Хитрости от мастеров.

### 3.5. Дилеры в РФ/СНГ

**Цели:**
- Узнать реальные цены (с дилерской наценкой).
- Получить каталоги с фото/ТТХ, которых нет на основном сайте.
- Узнать о сервисе, гарантии, сроках поставки.
- Собрать контакты для будущего маркетинга.

**Где искать:**
- Яндекс.Карты, 2ГИС: «Ижица дилер [город]».
- Пульс цен, Авито: «камера копчения Ижица».
- Форумы: «Horeca-magazine», «Пищепром».
- Промышленные выставки: «ПродЭкспо», «WorldFood», «Seafood Expo» (списки участников).

**Что собирать:**
- Название, ИНН, контакты.
- Каталог (PDF или HTML).
- Прайс.
- Условия (срок, гарантия, монтаж, обучение).
- Отзывы.
