## 3. Реальные цены (важно для конкурентного анализа)

Для каждой модели — собрать:
- **RRP (рекомендованная цена)** — от производителя.
- **Дилерская цена** — реальная, с дилерской скидкой.
- **Срок поставки** — от склада / на заказ.
- **Включено/не включено** — монтаж, обучение, пусконаладка.

## 4. Контакты для будущего маркетинга FELETI-SMOK
- Кто может стать **нашим дилером** (есть опыт, склад, сервис).
- Кто может **конкурировать** (если мы ставим в один регион).
