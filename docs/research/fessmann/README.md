## 4. Особенности Fessmann
- Немецкое качество, 100+ лет на рынке.
- FES.APP — лучшее мобильное приложение в отрасли (наша цель — превзойти).
- OPC UA — стандарт в индустрии, наш модуль расширения должен его поддерживать.
- Цены: 120 000 €+ (Turbomat, FES.APP включено в опции).

## 5. Что взять для FELETI-SMOK
1. **UX FES.APP** — мобильный дизайн, навигация, графики.
2. **Turbomat-принцип** — вентилятор + нагреватель + продукт в одном объёме (хорошая аэродинамика).
3. **CIP-мойка** — интегрированная система, опция для наших камер.
4. **OPC UA** — добавить в наш драйвер как опцию (для интеграции с заводами).
