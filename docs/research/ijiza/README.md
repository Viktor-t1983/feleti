> **Приоритет:** 🔴 P0 (максимальный фокус).  
> **Источник:** сайт + каталоги + TG + YouTube + дилеры.  
> **Старт:** сессия 2.

## 1. Цели

1. Собрать **полный каталог** продукции с ТТХ, ценами, фото.
2. Задокументировать **контроллер Varmen-1** (карта Modbus-регистров, режимы).
3. Собрать **50+ рецептов** из открытых источников.
4. Найти **дилеров в РФ** с реальными ценами.
5. Выявить **сильные и слабые стороны** для конкурентного анализа.

## 4. Что должно получиться

### 4.1. `catalog/`
- 18+ моделей в JSON (по шаблону из `../README.md`).
- Изображения (3–5 на модель).
- Цены (с пометкой источника: сайт / дилер / диапазон).
- Источник каждой записи.

### 4.2. `recipes/`
- 30+ рецептов из каталога + TG.
- Программы с фазами, T_chamber, T_product, временами, дымом.
- Указание источника (каталог, пост, видео).

### 4.3. `controllers/`
- Карта Modbus-регистров Varmen-1 (DRAFT → верифицированная).
- Holding registers (0x0000–0x003F).
- Input registers (0x1000–0x100B).
- Coils (0x2000–0x2004).
- Команды, диапазоны, единицы измерения.
- Источник (Wireshark-сниффинг, доки от Ижица, обратная разработка).

### 4.4. `dealers/`
- Список дилеров (10+ в РФ).
- Название, ИНН, контакты.
- Каталоги / прайсы.
- Условия (срок, гарантия, монтаж).

### 4.5. `telegram/`
- Извлечённые рецепты (с указанием поста).
- Программы.
- Проблемы/решения.
- Сравнения.

### 4.6. `youtube/`
- Транскрипты 10+ видео.
- Тайм-коды ключевых моментов.
- Извлечённые параметры.

## 5. Этика и право

- ✅ Парсить только публичные данные.
- ✅ Использовать как reference для своих рецептов (с указанием источника).
- ❌ Не копировать рецепты дословно (пересчитывать, адаптировать).
- ❌ Не перепубликовывать каталоги (только структурированные данные).
- ❌ Не обходить авторизацию, CAPTCHA, robots.txt disallow.
- ⚠️ Telegram — только публичные каналы, не личные сообщения.
