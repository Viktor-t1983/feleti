# Специалисты по копчению — партнёры и эксперты Ижицы

## Штатные технологи Ижицы

### 1. Сергей Кужелев — главный технолог Ижицы
- **Должность:** Главный технолог компании Ижица
- **Специализация:** Мясопереработка, цельнокусковое мясо, колбасы, технологические карты
- **Опыт:** Ведущий семинаров по мясным деликатесам, запуск цехов под ключ (в т.ч. в Казахстане), разработка рецептур
- **YouTube:** Контент на канале Ижицы (готовит, рассказывает технологии)
- **Telegram:** Личного нет, консультирует в @ijiza_chat

### 2. Андрей Колчанов — технолог Ижицы
- **Должность:** Технолог компании Ижица
- **Специализация:** Термокамеры, инъекторы, оборудование, копчение
- **Опыт:** Демонстрация оборудования (камера Z115.2-А, инъектор MI-2.2), разбор видов оболочек, видео на канале Ижицы
- **YouTube:** Канал Ижицы (ведёт рубрики про оборудование)
- **Telegram:** @ijiza_chat

### 3. Александр Лебедков — технолог Ижицы (рыба)
- **Должность:** Технолог компании Ижица
- **Специализация:** Рыбопереработка, холодное и горячее копчение рыбы, посол
- **Опыт:** Семинары по рыбе ХК и ГК, вебинары по рыбопереработке
- **Контент:** Видео на Rutube, выступления на семинарах Ижицы

### 4. Алексей Фомин — бренд-шеф Ижицы (Black Line)
- **Должность:** Бренд-шеф Ижицы, автор проекта Ижица Black Line
- **Специализация:** Ресторанное копчение, расчёт фудкостов, рецептуры для HoReCa
- **Опыт:** >20 лет, шеф-технолог, семинары в CHEFS LAB
- **YouTube:** Канал Ижицы (ресторанное направление)
