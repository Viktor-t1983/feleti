# Анализ HMI (панели управления) коптильных камер Ижица

> **Источники:** паспорт Ижица-Z115, сайт ijiza.ru, обучающие видео, каталоги дилеров.
> **Дата исследования:** 2026-06-03.
> **Цель:** Изучить UX/UI панели управления Ижицы для создания лучшего HMI в FELETI-SMOK.

---

## 1. Общая архитектура HMI Ижицы

### 1.1. Аппаратная платформа

| Параметр | Значение |
|----------|----------|
| Тип панели | Сенсорная панель оператора (промышленный HMI) |
| Размещение | Встроена в шкаф управления камеры |
| Хранение программ | USB-Flash накопитель внутри шкафа |
| Перенос программ | Между камерами Ижица-ГК с аналогичной панелью |

**Примечание:** Точная модель HMI-панели не указана в паспорте. Возможные варианты: Kinco, Weintek, или собственная разработка на базе Linux/RTOS + дисплей.

### 1.2. Емкость системы

| Параметр | Значение |
|----------|----------|
| Макс. программ | 1000 |
| Макс. шагов в программе | Практически неограниченно (в разных источниках: 99 шагов) |

## 2. Главный экран (Main Screen)

### 2.1. Отображаемые параметры (с паспорта Z115)

**Текущие (фактические) параметры:**
- Температура в камере (T_chamber)
- Температура продукта (T_product) — от датчика в сердцевине
- Температура "влажного" датчика (для расчета влажности)

**Целевые (заданные) параметры шага:**
- Время работы шага
- Целевая температура внутри продукта (T_product_target)
- Целевая влажность (поддерживается)
- Целевая температура камеры (T_chamber_target)

### 2.2. Индикаторы состояния (с видео)

- Индикаторы работы заслонок (вход/выход)
- Индикатор работы парогенератора
- Индикатор работы дымогенератора
- Индикатор работы вентилятора
- Индикатор нагрева (ТЭНы)

## 3. Режимы работы камеры

### 3.1. Технологические режимы (шаги программы)

| Режим | T камеры | Парогенератор | Заслонки | Назначение |
|-------|----------|---------------|----------|------------|
| **Прогрев** | 23-38°C | Выключен | — | Предварительный прогрев продукта, срабатывание нитритной соли, исключение "вскипания" белка |
| **Сушка** | 30-50°C | Выключен | Открыты (макс. поток воздуха) | Удаление влаги с поверхности перед копчением |
| **Жарка** | 70-85°C | Выключен | Закрыты | Создание "корочки", товарный вид, сокращение усушки |
| **Копчение** | 45-60°C | Выключен | Регулируются (вход ~50%, выход управляет тлением) | Наложение цвета и аромата, санитарная обработка дымом |
| **Варка** | 80-95°C | Автоматический (>80% RH) | Закрыты | Доведение до готовности (T_product 65-72°C), сохранение сочности |
| **Запекание** | >100°C | Импульсный (кратковременная подача воды с паузами) | Закрыты | Доведение до готовности при высокой T, "хрустящая корочка" |
| **Проветривание** | Выключен | Выключен | Открыты | Удаление остатков дыма после копчения |

### 3.2. Условия перехода на следующий шаг

1. **По времени** — шаг длится N минут
2. **По температуре продукта** — T_product достигает заданного значения
3. **Комбинированное** — например, "варка до T_product = 72°C, но не более 120 мин"

## 4. Управление программами

### 4.1. Список операций

1. **Выбор технологической программы** — из библиотеки
2. **Создание новой программы** — с нуля
3. **Редактирование существующей** — изменение параметров шагов
4. **Удаление программы**
5. **Запуск программы** — автоматический режим
6. **Одношаговый режим** — отладка программы пошагово
7. **Изменение "на лету"** — корректировка параметров текущего шага без остановки

### 4.2. Параметры шага (редактируемые)

| Параметр | Диапазон | Описание |
|----------|----------|----------|
| Время шага | 0-999 мин | Длительность шага (если переход по времени) |
| T камеры | 0-140°C | Целевая температура в камере |
| T продукта | 0-100°C | Целевая температура в сердцевине (условие перехода) |
| Влажность | Авто / Ручная | Управление парогенератором |
| Плотность дыма | Регулируется | Через заслонки дымогенератора |

### 4.3. Стандартные программы (из видео)

1. **СВИНИНА КВ** (копчено-вареная) — прогрев → сушка → копчение → варка
2. **СВИНИНА КВ ПР** (с прогревом) — прогрев → сушка → копчение → варка
3. **КУРА ВК** (варено-копченая курица) — прогрев → сушка → копчение → варка
4. **РЫБА ГК** (горячего копчения с плавным нагревом) — медленный нагрев → сушка → копчение → варка
5. **МОЙКА** — программа мойки камеры

## 5. Управление влажностью

### 5.1. Автоматический режим

- Подача воды в парогенератор автоматически
- Подстройка под давление в системе водоснабжения (2-4 бара)
- Целевая RH > 80% при варке

### 5.2. Ручной режим

- Оператор задает параметры подачи воды
- Импульсный режим для запекания (кратковременная подача с паузами)

### 5.3. Датчик влажности

- **Психрометрический метод** — два термометра: "сухой" и "влажный"
- Влажность рассчитывается по разности температур
- Требуется постоянное наличие воды в контейнере "влажного" датчика

---

## 6. Управление дымогенератором

### 6.1. Щеповый дымогенератор (DL400/DL450)

- **Входная заслонка** — регулирует подачу кислорода в зону тления
- **Выходная заслонка** — управляет тягой, температурой тления
- **Шибер** — автоматизация тяги возможна
- **Оптимальное тление** — темно-бордовые угли (не красные, не черные)

### 6.2. Фрикционный дымогенератор (Ф10/Ф15)

- Используется в моделях Z115.2-A
- Автоматическая подача щепы

### 6.3. Атомайзер (Varmen Atomic)

- Электростатическое копчение
- Отдельная система

---

## 7. Ручной режим

- Управление каждым элементом отдельно (ТЭНы, вентилятор, заслонки, парогенератор)
- Используется для тестирования, обслуживания, отладки

---

## 8. Сильные стороны HMI Ижицы

1. **Интуитивный интерфейс** — быстро осваивается операторами
2. **Библиотека рецептов** — готовые программы копчения
3. **Одношаговый режим** — удобная отладка программ
4. **Изменение "на лету"** — корректировка без остановки процесса
5. **Перенос программ** — между камерами через USB
6. **Графическое отображение** — текущие и целевые параметры на одном экране
7. **Многошаговые программы** — сложные технологические процессы

---

## 9. Слабые стороны / что можно улучшить

1. **Нет удаленного мониторинга** — оператор должен быть у камеры
2. **Нет мобильного приложения** — управление только с панели
3. **Нет облачной синхронизации** — программы на USB, нет централизованного хранилища
4. **Ограниченная визуализация** — ЖК-дисплей, нет цветных графиков трендов
5. **Нет предиктивной аналитики** — нет прогноза времени готовности
6. **Нет журнала партий** — нет автоматического учета выхода готовой продукции
7. **Нет фото/видео** — нет визуального контроля через камеру
8. **Психрометрический датчик влажности** — требует постоянного обслуживания (вода, фитиль)
9. **Нет интеграции с ERP/MES** — данные не выгружаются в производственную систему
10. **Один датчик T_product** — нет возможности мониторить несколько точек

## 10. Выводы для FELETI-SMOK HMI

### 10.1. Что взять от Ижицы

- Главный экран с текущими + целевыми параметрами
- 6 базовых режимов (прогрев, сушка, жарка, копчение, варка, запекание)
- Программы с условиями перехода (по времени / по T_product)
- Одношаговый режим отладки
- Изменение параметров "на лету"
- Библиотека рецептов
- Ручной режим для обслуживания

### 10.2. Что сделать лучше

- **Цветной сенсорный дисплей 7-10"** с современным UI (как планшет)
- **Графики трендов** — температура, влажность, дым в реальном времени
- **Web-интерфейс** — управление с телефона/планшета через WiFi
- **Облачная синхронизация** — программы в облаке, доступ с любой камеры
- **Видеокамера внутри камеры** — визуальный контроль через дисплей
- **Предиктивный таймер** — "до готовности осталось 15 минут"
- **Автоматический журнал партий** — запись всех параметров процесса
- **Push-уведомления** — алерты в Telegram/приложение
- **Многоточечные датчики** — T_product в 3-5 точках
- **Цифровой датчик влажности** — вместо психрометра (меньше обслуживания)
- **QR-код на партию** — сканируешь → видишь всю историю процесса
