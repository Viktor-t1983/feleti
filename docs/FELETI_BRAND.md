# FELETI — Бренд-гайд

> **Версия:** 0.1.0  
> **Применяется:** ко всем продуктам FELETI-SMOK (UI, документация, маркетинг, оборудование).

## 1. О бренде

**FELETI** — бренд ООО «АгроПищеПром», г. Брест, Беларусь. 17 лет на рынке, 870+ проектов, 300+ экспертов, 2600 м² производства, 27+ регионов. Слоган: **«Feel the progress»**.

**FELETI-SMOK** — новое направление: коптильные камеры собственного производства + софтверная платформа управления. Целевая аудитория — профессионалы пищепрома (B2B-заводы, цеха, крафт).

## 2. Ценности бренда

1. **Технологичность** — мы внедряем то, что конкуренты только обещают (AI, голос, оффлайн).
2. **Открытость** — открытый Modbus TCP, открытый API, открытая база знаний.
3. **Надёжность** — 17 лет без сбоев в поставках для партнёров.
4. **Партнёрство** — мы не продаём «коробку», мы даём инструмент и поддержку.
5. **Честность** — цена соответствует качеству, нет скрытых лицензий.

## 3. Тон голоса

- **Деловой, но не сухой.** Можно «ты» в чате, но в документах — «вы».
- **Конкретный.** Цифры, факты, ссылки на ГОСТ/источник.
- **Без понтов.** Не «революционная платформа», а «работает оффлайн в цеху 8 часов».
- **Технологичный.** Терминология корректная, без упрощений до потери смысла.

## 4. Логотип

**Концепт:** стилизованная буква **F** (или моноблок FELETI) в чёрно-красном исполнении.

**Пропорции:** лого в прямоугольнике 3:1, минимум 32 px высота для digital, 12 мм для печати.

**Свободное пространство:** ≥ 1× высота логотипа со всех сторон.

**Цветовые версии:**
- Полноцвет (на белом фоне): чёрный + красный акцент.
- Монохром (на тёмном фоне): белый.
- Инверсия (на красном фоне): белый.

**Файл:** `frontend/public/logo.svg`, `logo-mono.svg`, `logo-inverse.svg`.

- **Моноширинный:** **JetBrains Mono** или **Geist Mono** — для данных, телеметрии, ID, логов, кода.
- **Альтернатива (для печати):** **Inter** (тот же, что в UI, для единообразия).

## 7. Spacing (отступы)

Шкала кратна 4 px:
- `0` = 0
- `1` = 4 px
- `2` = 8 px
- `3` = 12 px
- `4` = 16 px
- `6` = 24 px
- `8` = 32 px
- `12` = 48 px
- `16` = 64 px
- `24` = 96 px

## 9. Тени

Минималистичные, в стиле Apple/Stripe:

```
shadow-sm:  0 1px 2px rgba(0, 0, 0, 0.05)
shadow-md:  0 2px 8px rgba(0, 0, 0, 0.08)
shadow-lg:  0 8px 24px rgba(0, 0, 0, 0.12)
shadow-xl:  0 16px 48px rgba(0, 0, 0, 0.16)
```

Для тёмной темы — `rgba(255, 255, 255, 0.05–0.16)` инверсия.

## 10. Анимации

- **Длительность:** 200 ms (быстрые), 300 ms (стандарт), 500 ms (медленные).
- **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (плавный, "ease-out-back").
- **Библиотека:** **Framer Motion** (React).
- **Принцип:** уважать `prefers-reduced-motion`.

## 11. Иконки

- **Lucide React** (open source, MIT) — основная библиотека.
- Стиль: line, 1.5 px stroke, 24×24 px viewport.
- Цвет иконки — `currentColor` (наследует от текста).

## 12. Компоненты shadcn/ui — кастомизация

shadcn/ui поставляется с нейтральной палитрой. **Кастомизируем** в `frontend/tailwind.config.ts`:

```ts
colors: {
  background: 'hsl(var(--background))',
  foreground: 'hsl(var(--foreground))',
  primary: { DEFAULT: '#E30613', foreground: '#FFFFFF' }, // FELETI Red
  // ...
}
```

CSS-переменные в `frontend/app/globals.css`:

```css
:root {
  --background: 0 0% 100%;
  --foreground: 0 0% 4%;
  --primary: 357 95% 46%; /* #E30613 */
  --primary-foreground: 0 0% 100%;
  /* ... */
}

.dark {
  --background: 0 0% 4%;
  --foreground: 0 0% 100%;
  /* ... */
}
```

## 13. Использование красного

**Красный `#E30613` — это бренд-цвет. Используем его ДОЗИРОВАННО:**

✅ Можно:
- Главная CTA-кнопка (одна на экран).
- Активный пункт меню.
- Логотип.
- Бренд-элементы (бедж FELETI, футер).
- Аварийные/критические состояния (но не для всех ошибок).

❌ Нельзя:
- Весь текст красным.
- Каждая кнопка красная (только primary).
- Иконки, которые должны быть нейтральными.
- Границы, разделители.
- Ссылки в тексте (они — синие или подчёркнутые).

**Правило:** красный = **1–5% площади экрана** максимум.

## 14. Тёмная и светлая темы

- **Дефолт:** тёмная тема (FELETI Black `#0A0A0A`).
- **Опция:** светлая тема (FELETI White `#FFFFFF`).
- **Переключатель:** в `header`, сохраняется в `localStorage`.
- **CSS:** через `prefers-color-scheme` + `class` стратегию (Tailwind).

## 16. Доступность (a11y)

- Контраст текст/фон ≥ 4.5:1 (WCAG AA).
- Все интерактивные элементы фокусируемы (`:focus-visible` стиль).
- Подписи к формам (`<label>`).
- ARIA-атрибуты для кастомных компонентов.
- Навигация с клавиатуры.
- Семантический HTML.

## 17. Использование на оборудовании

- **Корпус камеры:** нержавейка AISI 304 (или 430 для бюджетных), порошковая окраска — FELETI Black + красная полоса/бейдж.
- **HMI-экран:** тёмная тема по умолчанию, лого FELETI в углу.
- **Шильдик:** FELETI-SMOK + серийный номер + QR (ссылка на документацию).

## 18. Чего НЕ делать

- ❌ Использовать другие красные оттенки (только `#E30613`).
- ❌ Применять градиенты (только в hero, не в UI).
- ❌ Тени ярко-красные или ярко-синие.
- ❌ Скругления больше 16 px (это уже не «деловой» стиль).
- ❌ Стоковые фото людей в маркетинге (используем реальные фото цехов).
- ❌ Иконки в стиле «emoji» (только Lucide / line-icons).

## 19. Чек-лист перед релизом
