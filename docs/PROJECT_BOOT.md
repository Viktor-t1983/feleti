## 1. Что это за проект

**FELETI-SMOK** — это **hardware + software** проект: линейка коптильных камер собственного производства (FELETI, г. Брест, Беларусь) **плюс** fullstack-платформа управления ими (десктоп + PWA-мобильная) и база знаний о копчении.

**Бизнес-стратегия:** FELETI (Беларусь, Брест) входит на рынок промышленного коптильного оборудования с собственной линейкой камер + открытой софтверной платформой, чтобы конкурировать с **Ижица/Varmen** (РФ) и европейскими производителями (Mauting, Fessmann, Kerres).

**Hardware-стратегия (зафиксировано пользователем 2026-06-02):**
- **Стартовый сегмент:** Profi/Industrial, B2B-заводы, 100–250+ кг загрузки.
- **Контроллер камеры:** **Kinco** (HMI + PLC, Китай) + **собственный модуль расширения** (для электростатики, доп. датчиков, AI-на-борту).
- **Электростатическое копчение (10–30 кВ):** да, **опция** (апгрейд-модуль), не в базе.
- **Датчики:** всегда **максимальная комплектация** (Pt100 продукт + Pt100 камера, влажность, дым, ΔP, вентилятор, масса), финальная цена зависит от бюджета заказчика.
- **Дымогенератор:** **свой** (щепа + фрикционный + атомайзер).

**Целевая аудитория софта:**
- Технологи коптильных цехов (основные пользователи)
- Операторы коптильных камер
- Владельцы крафтовых цехов
- Менеджеры по продажам оборудования
- Инженеры-интеграторы (открытый Modbus TCP → могут интегрировать со своим софтом)

**Расположение проекта:** `D:\Коптильные камеры\koptilnya-platform`

## 7. Универсальный драйвер камеры (главная идея)

**Принцип:** UI не знает, какая камера подключена. Он работает с абстрактным **ChamberGateway**, который умеет:
- `get_capabilities()` — что умеет камера
- `get_telemetry()` — текущие показания (t, влажность, дым)
- `start_program(recipe)` — загрузить рецепт и запустить
- `pause()`, `resume()`, `stop()`
- `subscribe_telemetry(callback)` — стрим данных в реальном времени

**Драйверы** реализуют этот интерфейс для разных камер:
- `VarmenDriver` — Modbus TCP (Ижица/Varmen, контроллер Varmen-1)
- `FessmannDriver` — OPC UA (Fessmann Turbomat, FOOD.CON 2)
- `KerresDriver` — HTTP/REST (Kerres Anlagensysteme)
- `MautingDriver` — Modbus TCP (туннели)
- `SimulatedDriver` — мок (для разработки и демо)
- **`FELETI_SMOKDriver`** — **собственный** драйвер для камер FELETI-SMOK (Kinco HMI/PLC + свой модуль расширения, Modbus TCP)

**Двухуровневая архитектура камер FELETI-SMOK:**
```
[Kinco HMI/PLC]  ← Modbus TCP →  [Свой модуль расширения]  ← Modbus TCP →  [Backend / ChamberGateway]
   • Базовый I/O:                       • Электростатика 10–30 кВ (опция)   • Абстракция, рецепты,
   • ТЭН, вентилятор, дым-               • Доп. датчики (ΔP, газ, pH)         телеметрия, версионирование
     генератор, дверь                    • Локальный AI-инференс (опц.)       • WebSocket в PWA
   • Базовые датчики (Pt100, влажн.,     • Edge-cache рецептов
     дым, дверь)                         • MQTT-мост в облако (опц.)
```

**Гибридный доступ** (детали в `CAMERA_DRIVER.md`):
- Локальный канал: **Modbus TCP** (LAN, <100 мс, offline-safe) — приоритет.
- Облако: **MQTT/HTTPS** (опционально, для удалённого мониторинга).
- Graceful degradation: сбой LAN → автоматический fallback на облако.

Детали: [`docs/CAMERA_DRIVER.md`](CAMERA_DRIVER.md)

## 9. Ключевые соглашения

### Код
- **Python**: type hints везде, async где возможно, SQLAlchemy 2.0 style
- **TypeScript**: strict mode, no `any` (только осознанно)
- **Именование**: snake_case (Python), camelCase (TS/JS)
- **Линтеры**: ruff (Python), eslint+prettier (TS)
- **Комментарии в коде**: только зачем, не что (см. `system` промпт)

### БД
- Все ID — `int autoincrement`
- Все временные метки — `DateTime(timezone=True)`, UTC
- Enum-ы — отдельный SAEnum с именем
- Названия таблиц — `snake_case` во множественном числе
- Soft delete где уместно (`deleted_at`)
- Аудит: `created_at`, `updated_at`, `created_by_id`

### API
- Версионирование: `/api/v1/...`
- Ответы: JSON, Pydantic-схемы
- Ошибки: HTTPException с понятным message
- Документация: автогенерация OpenAPI (FastAPI)
- Авторизация: JWT в Authorization: Bearer

### Git
- main — стабильная
- feature/* — фичи
- commit: conventional commits (feat:, fix:, docs:, chore:)
- PR + ревью
