# SKILL: hmi-chamber — HMI панель управления коптильной камерой

> **Версия:** 0.1.0
> **Статус:** DRAFT
> **Приоритет:** 🔴 P0 (приоритет #1 по решению пользователя)
> **Цель:** Создать лучшую панель управления коптильной камерой, чем у Ижицы.

---

## 1. Контекст

Пользователь определил: **приоритет #1 — софт работы самой камеры (HMI)**, а не контроль качества после копчения. HMI — это то, что оператор видит на экране камеры: программы, температуры, фазы, графики в реальном времени.

Конкурент — Ижица (Z115, Varmen, UTR, DL). Нужно сделать **лучше по исполнению**.

## 2. Аппаратная платформа HMI

### 2.1. Варианты

| Вариант | Плюсы | Минусы | Рекомендация |
|---------|-------|--------|--------------|
| **Kinco HMI** (GL070E/GL100E) | Modbus RTU/TCP, 7-10", <$200, надёжный | Базовый UI, ограниченная графика | **Рекомендуется для базового HMI** |
| **Weintek/cMT** | Мощный UI, HTML5, WebView | Дороже (~$400), сложнее | Для премиум-моделей |
| **Raspberry Pi 7" + web UI** | Полная свобода дизайна, Linux | Не промышленный, требует корпус | Для прототипов/R&D |
| **Планшет Android + web app** | Дешево, WiFi, камера | Надёжность, сертификация | Для удалённого мониторинга |

### 2.2. Выбор для FELETI-SMOK (фиксировано)

**Kinco HMI GL070E или GL100E** — основной экран на камере.
**Web-интерфейс** — удалённый мониторинг с телефона/планшета.

### 3.4. Экран отладки (Debug / Single Step)

- Одношаговый режим — выполнять программу по шагам вручную
- Принудительный переход на следующий шаг
- Изменение параметров "на лету" без остановки
- Ручной режим для обслуживания (управление каждым элементом отдельно)

### 3.5. Экран графиков (Trends)

- График T_chamber за выбранный период
- График T_product
- График RH (влажности)
- График smoke density
- Масштабирование (1 час / 8 час / 24 час / 7 дней)
- Экспорт данных в CSV

### 3.6. Экран журнала (Log)

- История запусков программ
- Алерты и предупреждения
- Ошибки оборудования
- Время простоя

### 3.7. Экран настроек (Settings)

- Калибровка датчиков
- Язык интерфейса (RU/EN/中文)
- WiFi / Ethernet настройки
- Обновление прошивки через USB
- Системные настройки (дата/время, звук, яркость)

## 4. Параметры шага (Step Parameters)

| Параметр | Диапазон | Ед. изм. | Условие перехода |
|----------|----------|----------|------------------|
| T_chamber_target | 0-140 | °C | Да (достижение) |
| T_product_target | 0-100 | °C | Да (достижение) |
| Time | 0-999 | мин | Да (истечение) |
| RH_target | 0-100 | % | Нет (поддержание) |
| Smoke_density | 0-100 | % | Нет (поддержание) |
| Fan_speed | 0-100 | % | Нет |
| Damper_in | 0-100 | % | Нет |
| Damper_out | 0-100 | % | Нет |
| Damper_smoke | 0-100 | % | Нет |

**Условия перехода (OR):**
- По времени (time >= max_time)
- По T_product (T_product >= target)
- По T_chamber (T_chamber >= target)
- По delta-T (скорость нагрева)
- По кнопке оператора (ручной переход)

## 5. Алерты и безопасность

| Условие | Уровень | Действие |
|---------|---------|----------|
| T_chamber > 145°C | Критический | Аварийная остановка, отключение ТЭНов |
| T_product > 100°C | Критический | Аварийная остановка |
| Отклонение T от программы > 5°C | Предупреждение | Звуковой сигнал, запись в журнал |
| Нет воды для парогенератора | Предупреждение | Отключение парогенератора, сигнал |
| Дверь открыта во время работы | Предупреждение | Пауза программы |
| Вентилятор не работает | Критический | Аварийная остановка |
| Потеря связи с датчиком | Предупреждение | Переход на резервный датчик |

## 6. Связь с backend

```
┌─────────────┐    Modbus TCP     ┌─────────────┐    WebSocket    ┌─────────────┐
│   Kinco     │◄─────────────────►│   PLC       │◄───────────────►│   Backend   │
│   HMI 7"    │    (регистры)     │   (Kinco)   │    (MQTT/WS)    │   (FastAPI) │
└─────────────┘                   └─────────────┘                 └─────────────┘
                                                                         │
                                                                         ▼
                                                                  ┌─────────────┐
                                                                  │   Web UI    │
                                                                  │ (Next.js)   │
                                                                  └─────────────┘
```

**Modbus TCP карта (HMI ↔ PLC):**
- Holding Registers (0x0000-0x003F): уставки шага (T, время, влажность)
- Input Registers (0x1000-0x100B): текущие значения датчиков
- Coils (0x2000-0x2004): команды (старт, стоп, пауза, сброс)
- Discrete Inputs (0x3000-0x300F): статусы (ТЭНы, вентилятор, дверь)

## 7. Сравнение с Ижицей — что делаем лучше

| Функция | Ижица | FELETI-SMOK |
|---------|-------|-------------|
| Дисплей | ЖК, монохромный | Цветной TFT 7-10", как планшет |
| Графики трендов | Нет | Да, в реальном времени |
| Web-интерфейс | Нет | Да, управление с телефона |
| Облачная синхронизация | Нет (USB) | Да, через backend |
| Видеокамера внутри | Нет | Опция (IP-камера) |
| Push-уведомления | Нет | Telegram/app |
| Журнал партий | Нет | Автоматический |
| QR-код партии | Нет | Да |
| Несколько точек T_product | 1 датчик | 3-5 точек |
| Цифровой датчик RH | Психрометр (обслуживание) | Цифровой (Sensirion) |
| Предиктивный таймер | Нет | "До готовности: 15 мин" |
| Интеграция ERP/MES | Нет | API для интеграции |
| Количество программ | 1000 | Безлимитно (облако) |
