# SKILL: recipe-calc

> Расчёт характеристик рецепта: БЖУ, себестоимость, выход (yield), время. Используй при доработке калькулятора или добавлении новых формул.

## 1. Файлы

- `backend/app/services/recipe_calc.py` — основной движок (275 строк)
- `backend/app/api/v1/endpoints/recipes.py` — endpoints `/recipes/{id}/calc`
- `backend/app/schemas/calc.py` — Pydantic DTO для ответа

## 2. Формулы

### 2.1. БЖУ на 100 г готового продукта
```python
protein = Σ (ingredient.mass_kg * ingredient.protein_per_100g) / total_mass_kg / 10
fat     = Σ (ingredient.mass_kg * ingredient.fat_per_100g)     / total_mass_kg / 10
carbs   = Σ (ingredient.mass_kg * ingredient.carbs_per_100g)   / total_mass_kg / 10
kcal    = protein*4 + fat*9 + carbs*4
```

**Важно:** Это БЖУ **сырья**, не готового продукта. При копчении белок денатурирует, жир вытапливается, влага уходит. Для точного БЖУ нужна лаборатория.

### 2.2. Себестоимость
```python
total_cost = Σ (ingredient.mass_kg * ingredient.price_per_kg)
cost_per_kg_raw = total_cost / total_mass_kg
cost_per_kg_finished = total_cost / finished_mass_kg
```

### 2.3. Выход (yield)
```python
finished_mass_kg = raw_mass_kg * (1 - losses_percent / 100)
losses_percent = smoke_loss + salt_loss  # capped at 60%
```

### 2.4. Потери по типу копчения
| Тип | Потери, % | Примечание |
|---|---|---|
| Горячее | 32.0 | Колбасы в/к, мясо, птица: ужарка + варка |
| Полугорячее | 25.0 | Сосиски, сардельки |
| Холодное | 12.0 | Рыба, мясо х/к: только подсушка |
| Электро | 8.0 | Минимум потерь (быстрая обработка) |
| Универсальное | 25.0 | Среднее между горячим и холодным |

### 2.5. Потери при посоле
| Метод | Потери, % |
|---|---|
| Сухой | 4.0 |
| Мокрый | 2.0 |
| Шприцевание | 1.0 |
| Комбинированный | 3.0 |

### 2.6. Определение типа копчения по программе
```python
if any(electro_voltage_kv > 0 for phase in program):
```

## 3. Примеры расчётов

### Пример 1: Скумбрия горячего копчения
- Сырьё: 10 кг
- Горячее копчение + сухой посол = 32% + 4% = 36%
- Готовый продукт: 10 * (1 - 0.36) = 6.4 кг
- Выход: 64%

### Пример 2: Сёмга холодного копчения
- Сырьё: 10 кг
- Холодное копчение + мокрый посол = 12% + 2% = 14%
- Готовый продукт: 10 * (1 - 0.14) = 8.6 кг
- Выход: 86%

### Пример 3: Скумбрия электростатика
- Сырьё: 10 кг
- Электро + мокрый посол = 8% + 2% = 10%
- Готовый продукт: 10 * (1 - 0.10) = 9.0 кг
- Выход: 90%

## 4. Доработка формул

### 4.1. Добавить новый тип копчения
1. Добавить в `DEFAULT_LOSSES_PERCENT` в `recipe_calc.py`
2. Добавить логику определения в `_infer_smoke_type()`
3. Добавить тест в `tests/test_recipe_calc.py`
4. Обновить `add-recipe` SKILL

### 4.2. Добавить фактор потерь
```python
# Например: потери от пересушивания
DRYING_LOSS_PERCENT = {
    "normal": 0.0,
    "slight_overdry": 2.0,
    "overdry": 5.0,
}
```

## 5. Валидация результатов

| Параметр | Мин | Макс | Если вне диапазона |
|---|---|---|---|
| yield_percent | 30% | 110% | Предупреждение в UI |

| cost_per_kg | 0.01 | 10000 | Предупреждение |
